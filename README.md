# Portofolio — Muhamad Elmansya Darryl Fatha

Website portofolio pribadi (Managed Services & Operations Engineer), dibuat dengan **React + Vite + Tailwind CSS v4**.

## Menjalankan di komputer

```bash
npm install
npm run dev       # buka http://localhost:5173
npm run build     # hasil di folder dist/
```

## Mengubah isi

Semua teks (profil, keahlian, pengalaman, proyek, sertifikasi) ada di **`src/data/cv.js`**.
Isi `linkedin` dan `github` di file itu agar tombolnya muncul di bagian Kontak.

## Deploy gratis ke GitHub Pages

1. Push repo ini ke GitHub (branch `main`).
2. Di GitHub: **Settings → Pages → Source: GitHub Actions**.
3. Setiap push ke `main` akan otomatis build dan terbit.
